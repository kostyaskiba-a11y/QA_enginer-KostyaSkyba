  1. Select all articles that were written by user 1test and created between 2020-07-5 and 2020-07-7 (included), and order by a descending created date.

        Command:

        SELECT a.* FROM article a JOIN userprofile up ON a.author_id = up.id JOIN users u ON up.user_id = u.id WHERE u.username = '1test' AND date(a.createdAt) BETWEEN '2020-07-05' AND '2020-07-07' ORDER BY a.createdAt DESC;

  1. Select the usernames of users and the number of articles written by these users.

        Command:

        SELECT u.username, COUNT(a.id) AS articles_count FROM users u JOIN userprofile up ON up.user_id = u.id LEFT JOIN article a ON a.author_id = up.id GROUP BY u.username;
